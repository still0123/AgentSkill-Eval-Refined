# AgentSkill-Eval Refined v0.3.0-rc.2

发布日期：2026-08-04

## 定位

`v0.3.0-rc.2` 修复 Portfolio Demo 发布审计发现的完整性与可移植性问题。该版本仍是
Prerelease，Demo 仍为明确标记的 deterministic simulated evidence。

## 修复

- `demo verify` 以 audit bundle 为锚点，交叉校验报告、paired 统计、Trace、输入哈希和文件集合；
- wheel 内置 Demo Dataset 与 Skill，可在空目录零费用运行；
- 相同输入使用稳定 Experiment ID，同 workspace 重跑复用已有实验；
- Dashboard 支持导入 `paired-results.json` 与 `evidence-index.json`；
- Portfolio Demo 仅保留离线 Mock，真实 Agent 继续使用 `real preflight/smoke/run`；
- 移除 Refined 版残留的 MCP、Memory/RAG 和 Process Scenario 公共接口与样例；
- Tag Release 由 GitHub Actions 构建、校验、生成 SHA256SUMS 并附 provenance。

## 快速验证

```bash
python -m pip install agentskill_eval-0.3.0rc2-py3-none-any.whl
agentskill-eval demo run --workspace /tmp/portfolio-demo
agentskill-eval demo verify --workspace /tmp/portfolio-demo
```

预期结果：

```text
72 Runs
Invalid: 0
W/T/L: 5 / 6 / 1
Evidence Class: SIMULATED DEMO
Audit Bundle: VERIFIED
```

## 结论边界

该 Demo 证明评测、报告和证据校验链路可复现，不证明真实 Agent 或 Skill 的普遍性能提升。
