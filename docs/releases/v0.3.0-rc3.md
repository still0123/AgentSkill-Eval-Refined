# AgentSkill-Eval Refined v0.3.0-rc.3

发布日期：2026-08-05

## 定位

`v0.3.0-rc.3` 完成首个真实 observed-Agent Python Bug Fix Skill v1→v2 正向闭环，并新增
最小 Python Test Generation 配对评测。该版本仍为 Prerelease，所有真实结论仅适用于冻结的
公开 Git-history Cases、Agent、Runtime 与协议。

## 真实 Skill v2

- validation_search：v1 FAIL → v2 PASS，获得 1 个独立 WIN；
- regression、confirmation、locked：0 LOSS、0 INVALID；
- Search→Locked 合计 W/T/L：`1 / 3 / 0`；
- AI-assisted review 身份明确记录；
- 发布不可变 `python-bug-fix@2.0.0`；
- Evidence Release SHA-256：
  `04ea593b840bb68c24d87381cadea416872f58bf67e95d565aa832d0a36706f2`。

Skill v2 仅增加一条通用规则：修改后必须重新运行复现命令，失败时继续迭代。它不包含 Case ID、
仓库、路径、Patch 或答案。

## Test Generation

新增两 Case Python Test Generation family：

- Agent 只能编写 `agent_regression_test.py`，不能修改生产代码；
- Grader 要求生成测试在 before commit 失败、after commit 通过；
- 最终有效配对 W/T/L：`0 / 2 / 0`，INVALID：`0`；
- 该结果为真实负证据，不执行候选搜索、自动优化或版本发布。

## 工程更新

- observed final evaluation 与 Promotion workflow 支持显式 real-run 预算授权；
- Final/Promotion CLI 增加 `--confirm-real-run`、Run 与费用上限；
- FailureBridge 输出严格、Case 无关的行为摘要；
- Test Generation Dataset builder 提供三次隐藏 reference-oracle 稳定性验证；
- RealEvidenceRunner 从冻结 `metadata.yaml` 读取 Skill name/version，不再硬编码 Skill family。
