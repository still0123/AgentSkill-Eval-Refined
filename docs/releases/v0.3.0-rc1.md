# AgentSkill-Eval Refined Portfolio Release

发布日期：2026-08-04
类型：Portfolio release candidate

## 发布结论

`v0.3.0-rc.1` 是聚焦 Python Bug Fix Skill 配对评测的公开演示版本。它提供零费用离线 Demo、
可验证证据包和五分钟面试讲解路径，不是多租户生产平台。

## 核心能力

- without-Skill / with-Skill 和 Skill v1 / v2 配对实验；
- 不可变 DatasetVersion、Benchmark 重建与 split 泄漏检查；
- 规范化 Trace、失败诊断、成本和回归分析；
- Failure-guided Skill Evolution 与 Process/DeepSeek proposal 边界；
- 独立 confirmation、locked test、人工审核和不可变 SkillVersion；
- PASS / FAIL / INVALID 三态判定与 WIN / TIE / LOSS 配对比较；
- 本地只读 Dashboard 与五分钟作品集演示；
- `demo run` 生成、`demo verify` 校验的离线证据包。

## 安装验证

Python 3.9+：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install agentskill_eval-0.3.0rc1-py3-none-any.whl
agentskill-eval version
agentskill-eval demo run --workspace /tmp/portfolio-demo
agentskill-eval demo verify --workspace /tmp/portfolio-demo
```

期望版本：

```text
0.3.0rc1
```

## 证据边界

- 项目完成演示包含 12 个 Case、baseline/treatment 每臂 3 次，共 72 个 simulated Run；它证明
  评测链路、统计和审计包可复现，不证明真实模型性能。
- 已授权的 Stage 3 真实 train smoke 没有形成 eligible treatment failure，因此系统按设计停止在
  `INSUFFICIENT`，没有调用 DeepSeek proposal，也没有产生真实 Skill v2。
- Promotion 与 Evidence Release 端到端链路使用 Fake/simulated fixture，证明状态机、父版本关系、
  HTML 转义和篡改检测，不代表真实 Skill 改进。
- 真实 Agent 样本规模很小，只能作为 descriptive evidence，不能声称普遍提升。
- Demo 固定标记 `simulated=true` 和 `SIMULATED_DEMO`，不能作为真实性能证据。
- Dashboard 只读取本地冻结报告。

## 已知限制

- 没有 FastAPI、远程队列、账号权限、多租户或 Kubernetes 控制面；
- 尚未发布由真实失败驱动、真实模型生成并通过 locked test 的 Skill v2；
- 当前仅保留 Python Bug Fix 主线；
- 发布候选不承诺长期兼容，数据结构和 CLI 仍可能在稳定版前调整。
