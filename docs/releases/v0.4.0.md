# AgentSkill-Eval Refined v0.4.0

发布日期：2026-08-07

## 定位

`v0.4.0` 将项目从 Portfolio-Grade 升级为 Evidence-Grade。目标不是强求 Skill 正向提升，
而是让正向、无增益、回归和基础设施无效结果都具有正确语义、完整谱系和离线复核能力。

## 核心升级

- `PASS`、任务 `FAIL`、基础设施 `INVALID` 全链路分离；
- Case 使用 `WIN / TIE_POSITIVE / TIE_NEGATIVE / LOSS / INVALID`；
- 零增益、invalid 或任一 loss 不能被确认或晋级；
- Evidence 绑定 DatasetVersion、Skill、Runner、Agent executable、Agent engine、Attempt 和
  replay bundle；
- replay bundle 拒绝缺失、多余、修改、路径越界和软链接成员；
- 新 Benchmark 仓库通过 before-fail、after-pass、mutation-fail、alternative-pass 四重
  Oracle；
- Skill mutation 支持按 Markdown 标题替换完整 workflow section，同时兼容旧 append 规格；
- 第二 Runtime 使用本地 MLX、Qwen2.5-Coder 和 process Agent，通过同一 Evidence 合同；
- Dashboard 显式显示 Evidence class、primary estimand、evaluation split 和 invalid 数量。

## 冻结结果

| Evidence | 结果 | 决策边界 |
|---|---|---|
| Python Bug Fix 首次闭环 | `1 WIN / 3 TIE / 0 LOSS` | 仅证明冻结 4 Case 工程闭环 |
| Test Generation corrected replay | `0 / 2 / 0`，0 INVALID | 冻结 2 Case 无增益 |
| Python Bug Fix 扩展验证 | 114 Runs，`0 WIN / 19 TIE_NEGATIVE / 0 LOSS / 0 INVALID` | `NOT_CONFIRMED`，0/19 floor effect |
| Regression | 当前公开 observed Evidence 未观察到 | 未来任何 loss 必须保留并阻止晋级 |

扩展验证覆盖 6 个独立开源仓库，3 次重复，metered cost 为 0。该结果既不确认 v2 普遍有效，
也不证明其普遍无效。

## 本地发布

GitHub-hosted workflows 已移除。发布只接受本地完成的：

- Ruff、mypy、pytest；
- Dashboard typecheck、lint、test、production build；
- wheel 和 sdist；
- clean-room wheel install、version、Demo run/verify 和包导入；
- `SHA256SUMS` 与 `build-provenance.json` 离线校验。

`build-provenance.json` 是可复核的本地构建记录，不是第三方签名或云端 attestation。
